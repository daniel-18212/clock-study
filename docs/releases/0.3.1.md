## English

- Centered the flip line on the visible digits in the main and floating windows.
- Added an offline Windows x64 installer, a universal macOS disk image, and Linux x64 Debian and AppImage packages.
- Added installation and build guides in English and Brazilian Portuguese.

This preview has no trusted Windows publisher signature or Apple notarization. On Linux Wayland, floating window behavior depends on the compositor.
