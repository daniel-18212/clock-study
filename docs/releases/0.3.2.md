## English

- Added a signed ARM64 APK for direct installation on Android.
- Adapted the flip display and controls for touch, with Pomodoro, countdown and stopwatch.
- Android asks for notification permission at first launch and schedules completion alerts for the lock screen.

This Android preview uses a temporary signing key. Install future APKs signed with a different key after removing this preview. See the [installation guide](https://github.com/daniel-18212/clock-study#get-started) for platform requirements.

## Português (Brasil)

- Adicionamos um APK ARM64 assinado para instalação direta no Android.
- Adaptamos o relógio flip e os controles para toque, com Pomodoro, temporizador e cronômetro.
- O Android pede permissão de notificações na primeira abertura e agenda os avisos de término para a tela bloqueada.

Esta prévia para Android usa uma chave de assinatura temporária. Para instalar um APK futuro assinado com outra chave, remova esta prévia. Consulte o [guia de instalação](https://github.com/daniel-18212/clock-study/blob/main/README.pt-BR.md#primeiros-passos).
